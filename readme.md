# 卡淘球星卡实时盯盘分析大屏 — 平台使用说明

## 一、平台简介

本平台是一个**球星卡交易信息实时盯盘与数据分析工具**，核心功能是从卡淘网（cardhobby.com.cn）自动抓取球星卡在售/成交数据，并以可视化大屏的形式呈现市场全貌，帮助用户快速掌握价格分布、卖家动态和截标倒计时，同时支持"已出价"标记管理。

**适用场景**：球星卡收藏者/投资者在卡淘网进行交易前的市场调研、价格监控和出价管理。

---

## 二、技术架构概览

| 层级 | 技术栈 | 说明 |
|------|--------|------|
| 后端 | Flask + Playwright + Pandas | 提供 API 接口、无头浏览器爬虫、CSV 数据持久化 |
| 前端 | 原生 HTML/CSS/JS + ECharts + PapaParse | 可视化大屏、数据表格、本地 CSV 解析 |
| 运行环境 | Python 3.9.6 | 虚拟环境隔离，不依赖系统包 |

## 三、环境准备与安装

### 3.1 系统要求

- **操作系统**：macOS / Windows / Linux
- **Python 版本**：3.9 及以上
- **浏览器**：Playwright 内置 Chromium（无需手动安装浏览器）

### 3.2 安装步骤

```bash
# 1. 进入项目目录
cd card_env

# 2. 创建 Python 虚拟环境（如已有则跳过）
python3 -m venv .

# 3. 激活虚拟环境
# macOS / Linux:
source bin/activate
# Windows:
# .\Scripts\activate

# 4. 安装 Python 依赖
pip install flask playwright pandas openpyxl

# 5. 安装 Playwright 浏览器内核（首次运行必须执行）
playwright install chromium
```

### 3.3 依赖清单

| 包名 | 用途 |
|------|------|
| Flask | Web 框架，提供 API 和静态文件服务 |
| Playwright | 无头浏览器自动化，执行网页数据抓取 |
| Pandas | 数据处理，CSV 读写与合并 |
| openpyxl | Excel 文件支持（Pandas 可选依赖） |

## 五、功能使用指南

### 5.1 实时抓取（在线模式）

这是平台的核心功能，从卡淘网实时抓取交易数据。

**操作步骤**：

1. 在页面顶部搜索框中输入关键字，例如：`欧文 Prizm`、`詹姆斯 Select`、`东契奇 Noir`
2. 点击 **🚀 实时抓取** 按钮
3. 等待后台浏览器完成抓取（页面会显示加载遮罩，通常需要 10-60 秒，取决于搜索结果页数）
4. 抓取完成后，页面自动渲染数据

**注意事项**：

- 抓取过程中每页之间会随机等待 2-4 秒模拟人类操作，页数越多耗时越长
- 如果卡淘网结构变更或反爬策略升级，可能导致抓取失败
- 抓取期间请勿重复点击按钮（按钮会自动禁用）

### 5.2 本地 CSV 上传（离线模式）

如果已有之前抓取保存的 CSV 文件，可以直接上传分析，无需联网抓取。

**操作方式（二选一）**：

- **点击上传**：点击 **📁 选择本地 CSV / 拖入窗口** 按钮，选择 CSV 文件
- **拖拽上传**：直接将 CSV 文件拖入浏览器窗口，松开鼠标即可解析

**CSV 文件格式要求**：

文件应包含以下列（与实时抓取输出格式一致）：

| 列名 | 类型 | 说明 |
|------|------|------|
| Keyword | 文本 | 搜索关键字 |
| Seller_Name | 文本 | 卖家名称 |
| Card_Title | 文本 | 卡片标题 |
| Card_URL | 文本 | 卡片详情页链接 |
| Price_CNY | 数值 | 价格（人民币） |
| End_Time | 文本 | 截标剩余时间（如"2天3小时15分"） |
| Scrape_Time | 整数 | 抓取时的 Unix 时间戳 |
| Is_Bid | 文本 | 是否已出价（"是"/"否"） |

### 5.3 数据可视化

抓取或上传数据后，页面自动展示以下可视化内容：

#### KPI 指标卡（顶部四栏）

| 指标 | 说明 |
|------|------|
| 有效在售/成交总数 | 过滤掉价格为 0 的无效数据后的卡片总数 |
| 市场平均价格 | 所有有效卡片的平均价格 |
| 参与卖家总数 | 不重复的卖家数量 |
| 当前最高标价 | 所有卡片中的最高价格 |

#### 价格分布散点图

- 横轴为卡片序号（按价格排序），纵轴为价格
- 红色虚线标注市场均价参考线
- 鼠标悬停可查看卖家名称和卡片标题

#### 出卡量 Top 10 卖家柱状图

- 展示在售卡数量最多的前 10 名卖家
- 帮助识别市场中的活跃卖家

#### 价格区间占比饼图

- 将卡片按价格分为 5 个区间：100 元以下、100-500 元、500-1000 元、1000-3000 元、3000 元以上
- 鼠标悬停显示具体数量和占比

### 5.4 数据明细表格

表格展示所有有效卡片的详细信息，支持以下交互：

#### 筛选功能

- **标题搜索**：在"标题包含"输入框中输入关键词（如"银折"、"评级"、"10编"），实时过滤
- **卖家筛选**：从下拉框中选择特定卖家，仅展示该卖家的卡片

#### 排序功能

点击表头可按该列排序，再次点击切换升序/降序：

| 可排序列 | 排序逻辑 |
|----------|----------|
| 卖家名称 | 按中文拼音排序 |
| 当前价格 | 按数值大小排序 |
| 截标时间 | 按实时剩余时间排序（基于抓取时间戳动态计算） |
| 状态 | 按已出价/未出价排序 |

#### 截标时间实时倒计时

- 表格中的"截标时间"列会根据抓取时间戳实时递减
- **红色加粗**：剩余不足 1 小时，即将截标
- **灰色删除线**：已截标
- **普通样式**：正常倒计时

#### 卡片标题链接

- 卡片标题为蓝色超链接，点击可在新标签页打开卡淘网对应卡片详情页
- 无链接的标题显示为普通黑色文本

### 5.5 标记已出价

用户可以在表格中勾选卡片，将其标记为"已出价"状态。

**操作步骤**：

1. 在表格左侧勾选一张或多张卡片（已出价的卡片复选框为禁用状态）
2. 点击 **🏷️ 标记所选为"已出价"** 按钮
3. 系统将更新 CSV 文件中的 `Is_Bid` 字段，并刷新表格显示

**数据持久化**：

- 标记结果会同步写入 CSV 文件（`cardhobby_prices_{关键字}.csv`）
- 下次抓取同一关键字时，系统会自动合并历史"已出价"状态（通过卡片标题 + 卖家名称匹配）
- 即使卡片价格发生变化，只要标题和卖家一致，出价标记会被保留

**全选操作**：点击表头左侧的全选复选框可一键勾选/取消所有未出价的卡片

## 六、API 接口说明

### 6.1 搜索抓取接口

```
POST /api/search
```

**请求体**：

```json
{
  "keyword": "欧文 Prizm"
}
```

**成功响应**：

```json
[
  {
    "Keyword": "欧文 Prizm",
    "Seller_Name": "卖家A",
    "Card_Title": "2023 Prizm Kyrie Irving Silver",
    "Card_URL": "https://www.cardhobby.com.cn/market/detail/xxx",
    "Price_CNY": 128.0,
    "End_Time": "2天3小时15分",
    "Scrape_Time": 1717814400,
    "Is_Bid": "否"
  }
]
```

**错误响应**：

| 状态码 | 说明 |
|--------|------|
| 400 | 关键字为空 |

### 6.2 标记出价接口

```
POST /api/mark_bid
```

**请求体**：

```json
{
  "keyword": "欧文 Prizm",
  "items": [
    {
      "Card_Title": "2023 Prizm Kyrie Irving Silver",
      "Seller_Name": "卖家A",
      "Price_CNY": 128.0,
      "End_Time": "2天3小时15分"
    }
  ]
}
```

**成功响应**：

```json
{
  "success": true
}
```

**错误响应**：

| 状态码 | 说明 |
|--------|------|
| 400 | 缺少必要参数 |
| 404 | 找不到对应的 CSV 数据文件 |
| 500 | 服务器内部错误 |

## 七、数据文件说明

### 7.1 CSV 文件命名规则

抓取数据会自动保存为 CSV 文件，命名格式：

```
cardhobby_prices_{关键字}.csv
```

其中关键字中的空格替换为下划线。例如：

- 关键字 `欧文 Prizm` → 文件名 `cardhobby_prices_欧文_Prizm.csv`
- 关键字 `詹姆斯` → 文件名 `cardhobby_prices_詹姆斯.csv`

### 7.2 文件编码

CSV 文件使用 **UTF-8-BOM**（utf-8-sig）编码，可直接用 Excel 打开而不出现乱码。

### 7.3 数据合并机制

每次抓取时，如果同名的 CSV 文件已存在：

1. 读取历史文件中的 `Is_Bid`（已出价）状态
2. 通过 `Card_Title + Seller_Name` 组合作为唯一键进行匹配
3. 将历史出价标记合并到新抓取的数据中
4. 用新数据覆盖旧文件

## 九、常见问题

### Q1：抓取时提示"未抓取到任何数据"

**可能原因**：
- 搜索关键字在卡淘网上无匹配结果
- 卡淘网页面结构变更，CSS 选择器失效
- 网络连接异常

**解决方法**：
- 尝试更换关键字（如使用英文卡名）
- 检查网络连接是否正常
- 检查卡淘网是否可正常访问

### Q2：Playwright 安装浏览器失败

```bash
# 手动安装 Chromium
playwright install chromium

# 如果下载缓慢，可使用国内镜像
set PLAYWRIGHT_DOWNLOAD_HOST=https://npmmirror.com/mirrors/playwright  # Windows
export PLAYWRIGHT_DOWNLOAD_HOST=https://npmmirror.com/mirrors/playwright  # macOS/Linux
playwright install chromium
```

### Q3：CSV 文件用 Excel 打开乱码

CSV 文件使用 UTF-8-BOM 编码，通常 Excel 可正确识别。如仍乱码：
- 用记事本打开后另存为，编码选择"UTF-8 with BOM"
- 或在 Excel 中通过"数据 → 从文本/CSV"导入，手动选择 UTF-8 编码

### Q4：截标时间显示不准确

截标倒计时基于抓取时刻的时间戳计算，不会实时同步卡淘网服务器时间。如需精确时间，请点击卡片标题链接前往卡淘网查看。

### Q5：标记出价后下次抓取丢失

出价标记通过 `Card_Title + Seller_Name` 匹配合并。如果卖家修改了卡片标题，则无法自动匹配。建议在每次抓取后及时确认出价状态。

## 十、注意事项

1. **反爬风险**：本工具使用无头浏览器模拟人类操作，但频繁抓取仍可能触发卡淘网的反爬机制，建议控制抓取频率
2. **数据时效性**：抓取数据为快照，价格和库存会实时变化，仅供参考
3. **仅供个人使用**：本工具仅供个人市场调研使用，请遵守卡淘网的使用条款
4. **开发模式运行**：当前以 Flask debug 模式运行，不建议部署到公网环境
