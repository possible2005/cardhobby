# 卡片交易信息抓取工具 PRD

## 1. 项目背景与目标

### 1.1 背景
CardHobby（cardhobby.com.cn）是国内知名的球星卡交易社区，用户需要在平台上搜索球员卡片、查看价格、追踪卖家、出价购买。手动重复搜索费时费力，且容易遗漏新上架的卡片。

### 1.2 目标
构建一个基于 Flask 的 Web 服务，自动化完成以下任务：
- 关键字驱动的卡片交易信息抓取
- 关键字列表的定时自动监控
- 凑套系列的卡片清单管理
- 抓取结果与凑套清单的智能匹配，辅助用户决定是否出价

## 2. 用户角色

| 角色 | 描述 |
| --- | --- |
| 普通用户 | 通过前端页面（index.html）发起搜索、查看结果、标记出价 |
| 收藏玩家 | 维护多个凑套系列清单，希望快速识别新上架的目标卡片 |
| 系统管理员 | 配置监控关键字、调度时间，触发或停用自动监控 |

## 3. 功能模块

### 3.1 首页抓取

| 功能点 | 说明 |
| --- | --- |
| 关键字搜索 | 接收关键字，调用 Playwright 抓取 cardhobby.com.cn 的市场页 |
| 多页抓取 | 自动翻页直到没有下一页 |
| 数据落盘 | 抓取结果写入 `data/cardhobby_prices_<keyword>.csv` |
| 已出价状态合并 | 重新抓取时保留历史 CSV 中已标记的 `Is_Bid=是` 状态 |
| 标记出价 | 通过 API 将指定卡片在 CSV 中标记为已出价 |
| 抓取数据查询 | 通过 API 读取指定关键字的 CSV 数据返回 JSON |

### 3.2 自动监控

| 功能点 | 说明 |
| --- | --- |
| 配置管理 | 支持 `keywords`、`schedule_time`、`enabled` 字段 |
| 定时调度 | 后台线程每分钟检查，匹配时间则触发一次全量抓取 |
| 历史记录 | 每次抓取（手动 / 自动）均写入 `monitor_history.json` |
| 手动触发 | 通过 API 立即执行一次监控 |
| 历史删除 | 批量删除指定历史记录，并清理对应 CSV 文件 |

### 3.3 凑套管理

| 功能点 | 说明 |
| --- | --- |
| 系列创建 | 通过文本解析创建凑套系列，自动识别系列名与卡片编号/球员/球队 |
| 系列合并 | 同名系列再次提交时按编号去重合并 |
| 卡片状态更新 | 支持按索引或编号批量更新 `collected` 状态 |
| 系列删除 | 删除指定凑套系列 |
| 系列查询 | 列出所有凑套系列及其卡片 |

### 3.4 抓取-凑套联动

| 功能点 | 说明 |
| --- | --- |
| 标题匹配 | 对抓取结果按 `编号 / 中文名 / 英文名` 三种策略匹配凑套卡片 |
| 未搜集提示 | 标识抓取结果是否命中未搜集卡片（`Has_Uncollected_Match`） |
| 价格汇总 | 统计每个未搜集卡片在抓取结果中的命中次数、最低价、均价 |

## 4. 非功能性需求

| 维度 | 要求 |
| --- | --- |
| 性能 | 单次关键字抓取（含翻页）控制在 60 秒内；后台监控不阻塞主请求 |
| 兼容性 | 支持 macOS / Linux；Python 3.9+ |
| 并发安全 | 配置、历史、凑套数据文件读写使用 `threading.Lock` 保护 |
| 容错 | 单卡片解析失败不影响整体；单关键字抓取失败不影响其他关键字 |
| 可维护性 | 模块化拆分，路由用 Blueprint，文件路径用 config.py 统一管理 |

## 5. 数据存储说明

所有数据文件位于项目根目录的 `data/` 目录下，启动时自动创建。

| 文件 | 格式 | 用途 |
| --- | --- | --- |
| `data/monitor_config.json` | JSON | 监控配置（关键字、调度时间、开关） |
| `data/monitor_history.json` | JSON | 监控运行历史记录 |
| `data/collections.json` | JSON | 凑套系列清单 |
| `data/cardhobby_prices_<keyword>.csv` | CSV | 每个关键字的抓取结果 |

### CSV 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| Keyword | string | 搜索关键字 |
| Seller_Name | string | 卖家名称 |
| Card_Title | string | 卡片标题 |
| Card_URL | string | 卡片详情页 URL |
| Price_CNY | float | 价格（人民币） |
| End_Time | string | 结束时间 |
| Scrape_Time | int | 抓取时间戳 |
| Is_Bid | string | 是否已出价（"是"/"否"） |
